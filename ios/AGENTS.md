# Repository agent instructions

이 저장소는 iOS 입문자가 `plan.md`의 Telecom Companion 앱을 만들며 XP를 연습하는 학습 공간이다.

- iOS, Swift, SwiftUI, UIKit, Xcode, 테스트, 앱 설계 또는 `plan.md`의 학습 과제를 다루는 요청에서는 작업 전에 `skills/ios-xp-pair/SKILL.md`를 끝까지 읽고 따른다.
- 스킬이 특정 reference를 읽으라고 안내하면 해당 작업에 필요한 reference만 끝까지 읽는다.
- 사용자가 다른 언어를 요청하지 않는 한 설명과 페어링 대화는 한국어로 한다. 코드 식별자와 Apple API 이름은 원문을 유지한다.
- 사용자를 iOS 초보자로 전제하되, 이미 확인한 지식을 반복 설명하지 않는다. 실제 작업 중 드러난 이해도에 맞춰 설명 깊이를 조절한다.
- `plan.md`는 학습 방향의 기준이지 기계적으로 따라야 하는 체크리스트가 아니다. 현재 코드와 사용자의 목표를 먼저 확인한다.
- 사용자가 “개발 시작하자” 또는 이어서 진행하자고 하면 `courses/`의 체크 상태만 믿지 말고 코드·테스트·`homework/` 기록을 함께 확인해 마지막 Green 지점부터 재개한다.
- 과정 구현 중에는 필요한 production/test symbol 가까이에 학습 목적과 다음 테스트·최소 구현을 짧은 내비게이션 주석으로 남긴다. 완료된 TODO와 장문 튜토리얼 주석은 production 코드에 남기지 않는다.
- Day 완료 조건을 실제로 검증한 뒤에만 해당 Day와 전체 진도표를 체크하고, `homework/day-XX.md`에 코스 의도, Red-Green-Refactor, 복습 개념, 재현 명령, 확인 질문과 다음 Story를 정리한다.
