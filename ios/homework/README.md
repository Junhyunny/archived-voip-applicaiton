# Homework

완료한 Day의 학습 결과를 `day-XX.md`로 정리하는 디렉터리다.

각 문서는 그날 실제로 구현하고 검증한 내용을 기준으로 다음을 기록한다.

- 코스가 가르치려던 판단
- 사용자에게 보이는 구현 결과
- Red → Green → Refactor 흐름
- production/test code 내비게이션
- 복습할 iOS·Swift·설계 개념
- 직접 다시 실행할 명령과 확인 질문
- 남은 위험과 다음 Story

Day 완료 조건과 테스트를 충족하기 전에는 완료 Homework를 만들거나 진도표를 체크하지 않는다.
