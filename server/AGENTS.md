
# AGENTS.md

인터넷 전화에 관련된 기술 스택을 탐구하기 위한 스프링 애플리케이션 토이 프로젝트.

## 주의 사항

- 사용자가 질문하면, 질문에 대한 답변을 하되 수정이 필요한 부분을 직접 변경하지 않는다.
- 사용자가 명시적으로 요청하지 않았다면, 코드를 커밋하지 않는다.

## 커밋 리뷰 지침

- AI 에이전트가 직접 수정하지 않는다. 개발자가 학습을 위해 사용하기 때문에 수정 사항에 대한 설명만 필요하고, 개발자가 직접 변경하도록 유도한다.
- 학습된 서버 앱, Kotlin, Spring Framework 개발 패턴이 아닌 경우 이를 지적하고, 개선할 수 있는 방안을 제시한다.
- 비효율적인 처리나 부족한 예외 처리에 관련된 문제가 있는지 검토 후 개선할 수 있는 방안을 제시한다.
- 보안에 관련된 문제가 있는지 검토 후 개선할 수 있는 방안을 제시한다.
- 개선 이유에 대해서 구체적이고, 상세하게 설명한다.
